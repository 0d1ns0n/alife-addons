# ALifeRU: русификация и события

Включать после Project A-Life NPCs.

## Русификация

* Переводы интерфейса, песочницы, радио и игровых строк A-Life в `Translate/RU`.
* `ALifeRUSpeech.lua` подменяет отображение реплик, `ALifeRUVoice.lua` при запуске, при старте игры и через 3 минуты обходит таблицы реплик A-Life и заменяет английские реплики русскими (по хешу текста, ключи `RD_ALifeLine_<hash>`).
* Мод нельзя класть в папку с `projectalife` в названии: проверка совместимости A-Life покажет окно «мод отключён».

## События мира

16 сценариев, по которым мир живёт сам: налёты, война банд, байкеры, поджог, ответ шерифа, облава, блокпост с платой, засада на колонну, беженцы, сброс припасов, крушение вертолёта, помощь, мародёры, взрыв газа, поход орды, зачистка военных. Список с описаниями: [ALifeRU-events.md](ALifeRU-events.md).

* Новости о событиях показываются всплывающим окном и в радио.
* Запускать события вручную можно во вкладке «События» панели читов (CheatPanelPX).
* Для лагеря: `E.protectors` (защитники лагеря участвуют в событиях), `opts.site` (событие можно привязать к точке, например к воротам).
